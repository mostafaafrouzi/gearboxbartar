# دفتر مالی گیربکس اتوماتیک برتر

اپ وب سبک حسابداری تعمیرگاه (تک‌صفحه، بدون سرور). داده‌ها در **localStorage** همان مرورگر ذخیره می‌شوند.

## استفاده آنلاین

پس از deploy روی GitHub Pages:

`https://mostafaafrouzi.github.io/gearboxbartar/`

روی iPhone/Android: باز کردن در Chrome → منو → **Add to Home screen** / **نصب اپ**.

## پشتیبان‌گیری

از منوی **بیشتر → پشتیبان‌گیری** فایل JSON را در تلگرام یا Drive نگه دارید. برای دستگاه دیگر همان فایل را **بازیابی** کنید. تنظیمات آی‌پی‌پنل و صف پیامک هم داخل همان فایل است.

## پیامک مشتری (آی‌پی‌پنل)

منوی **بیشتر → پیامک مشتری**: پس از ترخیص خودرو و گذشت مدت تنظیم‌شده، پیشنهاد پیام در **صف** می‌آید (بدون ارسال خودکار). حسابدار متن را می‌بیند، در صورت نیاز ویرایش می‌کند و **تأیید و ارسال** می‌زند. قوانین ضد اسپم: یک یادآوری per پرونده، فاصله بین پیام به یک شماره، سقف سالانه، ساعات مجاز، و «عدم پیامک» در پرونده خودرو.

## توسعه محلی

فقط `index.html` را در مرورگر باز کنید یا با یک سرور استاتیک:

```bash
npx --yes serve .
```

## فونت و برند

- فونت: IRANSansX (Eco) در `assets/fonts/iransansx/` — مطابق مجوز FontIran.
- لوگو و favicon از [gearboxbartar.com](https://www.gearboxbartar.com/) (`icons/logo-top.png`, `icons/favicon.png`).
